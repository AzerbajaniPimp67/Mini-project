### 1. CSAPATADATOK
* **Csapatnév:** Solo Coders (1 fős egyéni megvalósítás)
* **Tagok:**
  * **Fürtös Levente** – Frontend Fejlesztő & Projektvezető
  * **Fürtös Levente** – UI/UX Tervező & HTML/CSS Fejlesztő
  * **Fürtös Levente** – JavaScript Fejlesztő & Tesztelő

---

### 2. FELADATMEGOSZTÁS
* **Fürtös Levente:** HTML5 szerkezet, CSS3 stíluslap és reszponzív (mobil/asztali) elrendezés kidolgozása.
* **Fürtös Levente:** Native JavaScript kód megírása (kategória alapú programszűrő és dinamikus űrlap-validáció).
* **Fürtös Levente:** Dokumentációs csomag elkészítése, tesztelés, tesztjegyzőkönyv és egyéni reflexiók összeállítása.

---

### 3. FORRÁSOK & FELHASZNÁLT TECHNOLÓGIÁK
* **HTML5 & CSS3:** Flexbox, CSS Grid, Media Queries
* **JavaScript:** Vanilla JS (DOM manipuláció, Event Listener-ek, Regex validáció)
* **Referenciák:** 
  * MDN Web Docs (HTML/CSS/JS referencia)
  * W3Schools (Form validation & Responsive Design)

---

### 4. INDÍTÁS ÉS HASZNÁLAT
1. Töltsd le vagy klónozd a projekt gyökérmappáját.
2. Nyisd meg az `index.html` fájlt bármilyen modern böngészőben (Chrome, Firefox, Edge, Safari).
3. Az oldal teljes egészében offline működik, nem igényel internetkapcsolatot vagy külön webszervert.
